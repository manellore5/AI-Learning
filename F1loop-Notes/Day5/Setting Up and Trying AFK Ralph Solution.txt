## Skills Fixing Docker Issues

![tests are failing due to native module version mismatch](https://res.cloudinary.com/total-typescript/image/upload/v1773347097/ai-hero/claude-code-cohort/wzpntxd7rrpwzzsih2oi.jpg)

Now here we go, this is super interesting. The tests are all failing due to a `better-sqlite3` native module version mismatch. Now this is something that I noticed when I was building the app because I actually used Ralph to build the app. I used AFK Ralph. I noticed that between my setup and the Docker setup, when I ran `npm install` kind of locally it would install the native module differently. So I added the skill inside `.claude/skills/better-sqlite-rebuild`.

![adding skill](https://res.cloudinary.com/total-typescript/image/upload/v1773347098/ai-hero/claude-code-cohort/xfwjiqk7eexyxanu7xul.jpg)

So this is a very satisfying moment for me because inside the Docker container it is picking up the local project-based skills and those skills are then steering its behavior to actually fix issues it's seeing. So this is one of the downsides of Docker Sandbox: it is a different environment to your environment. However we can see that thanks to the skill it was able to rebuild successfully and it ran the test again.
